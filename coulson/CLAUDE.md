# Колсон — инструкция для Claude Code на Маке пользователя

Ты работаешь локально на MacBook Pro M1 Pro 16 ГБ, macOS Tahoe (26). Задача — установить, запустить
и отладить «Колсона», локального голосового ассистента в духе Джарвиса. Общайся с пользователем по-русски.

## Что это
- Всегда слушает микрофон (Silero VAD) → Parakeet TDT 0.6B v3 на MLX (ru+en, ~5.5% WER на русском, десятки мс
  на фразу; Whisper large-v3-turbo — запасной, `stt.engine: whisper`) → слово-активатор «Колсон» (нечёткое сравнение).
- Мозг: Ollama + `qwen3-vl:8b-instruct` (зрение + инструменты в одной модели, ~6 ГБ).
- Цвет шара: голубой; при предупреждениях/ошибках/плохих новостях краснеет (метка `[ok]/[warn]/[bad]` в начале
  ответа модели + оценка по словам и по ошибкам инструментов), через `ui.mood_hold_seconds` возвращается.

## Почему именно эти модели (не меняй без замера `--bench`)
- **Скорость = кэш промпта.** Системный промпт + инструменты ≈ 3.5 тыс. токенов. На M1 Pro Ollama (движок
  llama.cpp — MLX-движок Ollama требует > 32 ГБ) обрабатывает промпт ~200–250 ток/с: без кэша это ~15 с на
  КАЖДУЮ реплику, с кэшем ~1 с. Поэтому начало промпта неизменно (время и картинки — в конце, факты — отдельным
  сообщением после инструментов), а при старте промпт прогревается (`Brain.warmup`).
- **Qwen3.5 (9B/4B) не подходит по умолчанию**: гибридная архитектура (Gated DeltaNet) ломает переиспользование
  кэша в llama.cpp/Ollama (llama.cpp #20225, открыт) → полная переобработка промпта на каждой реплике.
  Если в свежей Ollama это починят — `--bench` покажет «кэш промпта ✅» и можно вернуть `qwen3.5:9b`
  (+ `think: false`, иначе ломается tool calling).
- **Qwen3-VL 8B Instruct**: обычное внимание (кэш работает), зрение и инструменты в одной модели,
  хороший русский, без режима размышлений (быстрый первый токен). Запас: `gemma4:e4b` (vision+tools, быстрее,
  но жалобы на tool calling), `gemma4:12b` (умнее, но ~8 ГБ и медленнее — впритык для 16 ГБ).
- **Parakeet вместо Whisper**: Whisper всегда считает 30-секундное окно → ~0.5–1 с GPU на КАЖДУЮ услышанную фразу
  (разговоры рядом, ТВ) — греет Мак и мешает играм. Parakeet считает только реальную длину фразы.
  Минус: нет подсказки-промпта, поэтому «Колсон» может записаться по-разному — смотри `🎙` в логе и дополняй
  `assistant.wake_words`. Если распознавание имени плохое — `stt.engine: whisper`.
- **Память**: Ollama ≈ 7 ГБ (модель + кэш q8_0), Колсон ≈ 2 ГБ. Запуск игры (Steam/Epic/категория «Игры»)
  выгружает модель (`llm.unload_on_game`), голосом — «Колсон, игровой режим». `keep_alive: 60m`.
- Голос: Silero v5 `aidar` (русский), `say -v Daniel` (британский английский). Экспериментально — Qwen3-TTS.
- Окно: pywebview, маленькая «таблетка» в правом верхнем углу, сворачивается в шар.
- Инструменты: `coulson/tools/*.py` (приложения/игры, браузер Yandex, поиск, зрение, shell, AppleScript,
  Shortcuts, горячие клавиши, громкость/медиа, таймеры, буфер, память, VPN-заготовка) и файлы
  (`files.py`: write_file — HTML/текст/код, create_table — Excel/CSV с диаграммой, read_file, list_dir, disk_usage).
  Созданные файлы по умолчанию — в `~/Documents/Колсон`.
- Второй мозг (`memory.py`): SQLite `memory.db` — facts, notes (заметки/задачи, теги, done), log (все реплики).
  Поиск гибридный: векторы `qwen3-embedding:0.6b` (Ollama, считаются в фоне) + FTS5, слияние RRF.
  `Brain._recall_block` подмешивает 2–3 похожие записи в КОНЕЦ сообщения пользователя (порог
  `memory.recall_min_similarity`). Без модели эмбеддингов всё работает по словам. Ollama держит 2 модели
  (`OLLAMA_MAX_LOADED_MODELS=2`), иначе мозг и эмбеддинги вытесняют друг друга.
- План (`tools/plan.py`): для задач из 3+ действий модель делает `plan set`, после каждого шага `plan done`;
  если остановилась с невыполненными шагами — `Brain.respond` один раз напоминает. `llm.max_tool_rounds: 20`.
- Мышь (`tools/mouse.py`): `click` — снимок главного экрана → `Brain.locate` (grounding Qwen3-VL, координаты
  0–1000, запрос с тем же началом диалога — кэш не сбрасывается) → клик Quartz; `mouse` — прокрутка,
  перетаскивание, клик в точку. Нужен «Универсальный доступ». Только главный экран. Клики по «Удалить/
  Купить/Отправить…» — с подтверждением.
- Опасные действия (rm, sudo, kill, выключение, отправка сообщений…) требуют голосового «да» — `coulson/safety.py`.

## Установка (по шагам, проверяй каждый)
1. `cd` в папку `coulson` репозитория и выполни `./scripts/setup.sh`.
   Скрипт ставит Homebrew (если нет, может спросить пароль — попроси пользователя ввести его в терминале),
   uv, Ollama (+ настройки: Flash Attention, кэш q8_0, 1 слот — через LaunchAgent `local.coulson.ollama-env`),
   скачивает `qwen3-vl:8b-instruct` (~6 ГБ), делает `uv sync`, скачивает Parakeet/Silero,
   собирает `~/Applications/Coulson.app`, запускает `--check` и `--bench`.
2. Если какой-то шаг упал — почини и перезапусти скрипт (он идемпотентный).
3. Проверь по частям, прежде чем запускать всё вместе:
   - `uv run python -m coulson --check` — все пункты ✅.
   - `uv run python -m coulson --bench` — **главная проверка скорости**. Ориентиры для M1 Pro:
     распознавание < 300 мс на фразу и «Колсон распознан»; прогрев мозга 10–20 с (один раз);
     поиск по смыслу: первой находится заметка про Грузию, < 500 мс;
     первое слово < 2.5 с; **кэш промпта ✅ (вторая реплика < 600 новых токенов)**; генерация ≥ 18 ток/с;
     вызов инструмента `open_app`; синтез голоса < 300 мс. Покажи пользователю итог и разбери каждое ⚠️/❌.
   - `uv run python -m coulson --say "Добрый вечер. Все системы в норме."` — должен прозвучать голос.
   - `uv run python -m coulson --tool open_app '{"name": "Steam"}'` — и ещё несколько инструментов
     (`web_search`, `weather`, `sound`, `look` с `{"source": "screen", "question": "что на экране"}`).
   - `uv run python -m coulson --tool click '{"target": "значок Apple в левом верхнем углу"}'` — должен открыться
     меню Apple (проверка зрения + мыши; если промахивается — см. «Если что-то не работает»).
   - `uv run python -m coulson --text` — текстовый диалог с моделью: проверь, что она вызывает инструменты
     («открой Яндекс Браузер», «какая погода», «что у меня на экране?», «запомни, что моя любимая игра — …»,
     «сделай таблицу загрузки диска с диаграммой», «напиши HTML-страницу-визитку»).
4. Запусти приложение: `open ~/Applications/Coulson.app`. Лог: `tail -f ~/Library/Logs/Coulson.log`.
5. Разрешения (выдаёт пользователь, ты объясняешь где): Системные настройки → Конфиденциальность и безопасность:
   - Микрофон → Колсон (спросит сам при первом запуске);
   - Запись экрана и системного звука → Колсон (для `look`), после выдачи перезапустить приложение;
   - Камера → Колсон (спросит при первой просьбе посмотреть);
   - Универсальный доступ → Колсон (для `type_text`, медиа-клавиш, `lock_screen`);
   - Автоматизация → разрешать по запросу (System Events, Finder, Yandex, Music…);
   - Файлы и папки (Рабочий стол, Документы, Загрузки) → разрешать по запросу; для полного анализа диска
     (`disk_usage` по ~/Library) можно выдать «Полный доступ к диску».
   Если после пересборки .app разрешения «слетели» — это из-за ad-hoc подписи: удалить Колсона из списка и выдать снова.
   - Полный доступ к диску → Колсон — рекомендую: иначе `disk_usage`/`find_files` вызовут пачку запросов про папки.
6. Автозапуск: `./scripts/autostart.sh on`.

## Как устроена надёжность (не ломай)
- Лаунчер `Coulson.app` перезапускает Колсона при падении (до 5 раз за 2 минуты); код выхода 0 — штатный
  выход без перезапуска («Колсон, выключись», кнопка × в окне, вторая копия).
- Вторая копия не запускается (`coulson.lock` в папке данных).
- Звук играет `afplay`/`say` (всегда текущее устройство вывода, AirPods и т.п.); микрофон — sounddevice со
  «сторожем»: 3 с без звука → переподключение с обновлением списка устройств (сон Мака, отключили микрофон).
- Время фраз — по моменту записи (для защиты от эха), продолжение без «Колсон» — только для фраз после ответа.
- Если Ollama при входе в систему ещё не поднялась — Колсон ждёт её до минуты.
- Лог ротируется: `~/Library/Logs/Coulson.log` (5 МБ × 3).

## Если что-то не работает
- **Поиск по смыслу не работает** (`--bench` ❌/⚠️): `ollama pull qwen3-embedding:0.6b`, проверь
  `launchctl getenv OLLAMA_MAX_LOADED_MODELS` = 2. Автоподсказки подмешивают лишнее — подними
  `memory.recall_min_similarity` (0.6–0.65); ничего не подмешивают — опусти (0.5).
- **Бросает задачу на полпути**: смотри в логе вызовы `plan`; можно поднять `llm.max_tool_rounds`.
- **`click` промахивается**: в логе строка `locate «…» → {...}` — что ответила модель. Если координаты
  разумные, а клик мимо — проверь `mouse._screen()` (главный экран) и что снимок делается с него (`-D 1`).
  Если модель не находит элемент — уточни описание или подними `vision.max_width` до 1920 (точнее, но медленнее).
- **Колсон не запускается повторно**: уже работает копия (см. `pgrep -fl "python -m coulson"`); лишнюю — `kill`.
- **Нет запроса на микрофон / тишина в логе**: проверь, что запускается именно `Coulson.app` (лаунчер
  `Contents/MacOS/Coulson` порождает python дочерним процессом, разрешения наследуются). Для отладки можно
  запускать из Terminal: `uv run python -m coulson -v` (тогда разрешения берутся у Terminal).
  Устройство выбирается в `audio.device` (список — в `--check`).
- **Реагирует на посторонние звуки / не слышит «Колсон»**: смотри строки `🎙` в логе — как распознавание пишет имя.
  Добавь вариант в `assistant.wake_words` или поменяй `wake_threshold`. Порог VAD — `audio.vad_threshold`,
  отсев шума Parakeet — `stt.min_confidence`. Не помогает — `stt.engine: whisper` (медленнее, но с подсказкой имени).
- **`--bench`: кэш промпта ❌** (каждая реплика медленная): проверь `ollama --version` (обнови), что
  `launchctl getenv OLLAMA_NUM_PARALLEL` = 1, что в `config.local.yaml` не выбрана гибридная модель (qwen3.5/3.6),
  и что ничего не дописывает меняющийся текст в начало промпта (`Brain._prefix`).
- **Слышит сам себя**: при речи из динамиков фразы без «Колсон» игнорируются (`Speaker.overlaps`). Если всё равно
  ловит эхо — увеличь хвост в `tts.py` (`+ 0.5`) или выключи `audio.barge_in`.
- **Модель печатает вызовы инструментов текстом**: есть запасной парсер (`brain.parse_text_tool_calls`); обнови
  Ollama. Альтернативы модели — см. «Почему именно эти модели»; после смены — снова `--bench`.
- **Шар не краснеет / краснеет зря**: модель должна начинать ответ с `[ok]/[warn]/[bad]` (видно в логе `←`/истории);
  запасная оценка по словам — `textutil.mood_of`.
- **Медленно**: сначала `--bench` — он покажет, что именно. `llm.num_ctx` можно снизить до 8192.
- **HTML/таблицы выходят слабыми**: 8B-модель пишет длинные файлы небыстро (~20 токенов/с) и проще, чем
  облачные. Пока модель пишет, Колсон говорит «Минутку, работаю» (`assistant.filler_after_seconds`).
- **Память**: модель выгружается после `keep_alive: 60m` простоя и при запуске игры — это нарочно.
  Первая просьба после выгрузки занимает ~15 с (загрузка + прогрев промпта).
- **Silero не грузится** (torch.hub без сети / ошибка): Колсон автоматически перейдёт на русский голос macOS.
  Посоветуй пользователю скачать «Юрий (улучшенный)» в Настройки → Универсальный доступ → Устный контент → Системный голос → Управление голосами.
- **Окно**: если `transparent`/`focus=False` в pywebview ведут себя странно на Tahoe — поправь `coulson/ui/window.py`.
  Режим без окна: `ui.enabled: false` в `config.local.yaml`.
- **Qwen3-TTS (британский тембр по-русски)**: `COULSON_QWEN3TTS=1 ./scripts/setup.sh`, затем
  `./scripts/make_voice_ref.sh` и `tts.engine: qwen3`. API mlx-audio меняется — сверь сигнатуры
  `load_model(...).generate(...)` в установленной версии и поправь `Speaker._synth_qwen`. Если медленно
  (> 1 с на фразу) — вернуть `silero`.

## Обновление
`./scripts/update.sh` — git pull, uv sync, ollama pull, тесты, перезапуск работающего Колсона.

## Правила для правок
- Настройки пользователя — только в `config.local.yaml` (не в `config.yaml`).
- Новый инструмент: функция с декоратором `@registry.add(...)` в `coulson/tools/`, для опасных — `risk=`.
- Тесты: `uv run --group dev pytest -q`.
- VPN пользователь настроит позже: секция `vpn` (`scutil` — имя подключения из Настроек, `shortcut` — команды
  «<name> On/Off», `app` — имя приложения).
