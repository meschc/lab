# Колсон — инструкция для Claude Code на Маке пользователя

Ты работаешь локально на MacBook Pro M1 Pro 16 ГБ, macOS Tahoe (26). Задача — установить, запустить
и отладить «Колсона», локального голосового ассистента в духе Джарвиса. Общайся с пользователем по-русски.

## Что это
- Всегда слушает микрофон (Silero VAD) → Whisper large-v3-turbo на MLX → слово-активатор «Колсон» (нечёткое сравнение).
- Мозг: Ollama + `qwen3.5:9b` (видит изображения, умеет вызывать инструменты). `think: false` обязательно —
  с thinking у Qwen3.5 в Ollama ломается tool calling.
- Голос: Silero v5 `aidar` (русский), `say -v Daniel` (британский английский). Экспериментально — Qwen3-TTS.
- Окно: pywebview, маленькая «таблетка» в правом верхнем углу, сворачивается в шар.
- Инструменты: `coulson/tools/*.py` (приложения/игры, браузер Yandex, поиск, зрение, shell, AppleScript,
  Shortcuts, горячие клавиши, громкость/медиа, таймеры, буфер, память, VPN-заготовка) и файлы
  (`files.py`: write_file — HTML/текст/код, create_table — Excel/CSV с диаграммой, read_file, list_dir, disk_usage).
  Созданные файлы по умолчанию — в `~/Documents/Колсон`.
- Опасные действия (rm, sudo, kill, выключение, отправка сообщений…) требуют голосового «да» — `coulson/safety.py`.

## Установка (по шагам, проверяй каждый)
1. `cd` в папку `coulson` репозитория и выполни `./scripts/setup.sh`.
   Скрипт ставит Homebrew (если нет, может спросить пароль — попроси пользователя ввести его в терминале),
   uv, Ollama, скачивает `qwen3.5:9b` (~6.6 ГБ), делает `uv sync`, скачивает Whisper/Silero,
   собирает `~/Applications/Coulson.app`, запускает `--check`.
2. Если какой-то шаг упал — почини и перезапусти скрипт (он идемпотентный).
3. Проверь по частям, прежде чем запускать всё вместе:
   - `uv run python -m coulson --check` — все пункты ✅.
   - `uv run python -m coulson --say "Добрый вечер. Все системы в норме."` — должен прозвучать голос.
   - `uv run python -m coulson --tool open_app '{"name": "Steam"}'` — и ещё несколько инструментов
     (`web_search`, `weather`, `volume`, `look_at_screen`).
   - `uv run python -m coulson --text` — текстовый диалог с моделью: проверь, что она вызывает инструменты
     («открой Яндекс Браузер», «какая погода», «что у меня на экране?», «запомни, что моя любимая игра — …»,
     «сделай таблицу загрузки диска с диаграммой», «напиши HTML-страницу-визитку»).
4. Запусти приложение: `open ~/Applications/Coulson.app`. Лог: `tail -f ~/Library/Logs/Coulson.log`.
5. Разрешения (выдаёт пользователь, ты объясняешь где): Системные настройки → Конфиденциальность и безопасность:
   - Микрофон → Колсон (спросит сам при первом запуске);
   - Запись экрана и системного звука → Колсон (для `look_at_screen`), после выдачи перезапустить приложение;
   - Камера → Колсон (спросит при первой просьбе посмотреть);
   - Универсальный доступ → Колсон (для `type_text`, медиа-клавиш, `lock_screen`);
   - Автоматизация → разрешать по запросу (System Events, Finder, Yandex, Music…);
   - Файлы и папки (Рабочий стол, Документы, Загрузки) → разрешать по запросу; для полного анализа диска
     (`disk_usage` по ~/Library) можно выдать «Полный доступ к диску».
   Если после пересборки .app разрешения «слетели» — это из-за ad-hoc подписи: удалить Колсона из списка и выдать снова.
6. Автозапуск: `./scripts/autostart.sh on`.

## Если что-то не работает
- **Нет запроса на микрофон / тишина в логе**: проверь, что запускается именно `Coulson.app` (лаунчер
  `Contents/MacOS/Coulson` порождает python дочерним процессом, разрешения наследуются). Для отладки можно
  запускать из Terminal: `uv run python -m coulson -v` (тогда разрешения берутся у Terminal).
  Устройство выбирается в `audio.device` (список — в `--check`).
- **Реагирует на посторонние звуки / не слышит «Колсон»**: смотри строки `🎙` в логе — как Whisper пишет имя.
  Добавь вариант в `assistant.wake_words` или поменяй `wake_threshold`. Порог VAD — `audio.vad_threshold`.
- **Слышит сам себя**: при речи из динамиков фразы без «Колсон» игнорируются (`Speaker.overlaps`). Если всё равно
  ловит эхо — увеличь хвост в `tts.py` (`+ 0.5`) или выключи `audio.barge_in`.
- **Модель печатает вызовы инструментов текстом**: есть запасной парсер (`brain.parse_text_tool_calls`); проверь
  версию Ollama (нужна свежая, ≥ 0.17.6), `think: false`. Альтернативы модели: `qwen3.5:4b` (быстрее),
  `gemma4:e4b` / `gemma4:12b` (тоже vision + tools).
- **Медленно**: `llm.num_ctx` меньше (8192), модель `qwen3.5:4b`. Whisper можно заменить на
  `mlx-community/whisper-large-v3-turbo-q4` если такой репозиторий доступен, или `whisper-small-mlx` (хуже русский).
- **HTML/таблицы выходят слабыми**: 9B-модель пишет длинные файлы медленно (~20 токенов/с) и проще, чем
  облачные. Пока модель пишет, Колсон говорит «Минутку, работаю» (`assistant.filler_after_seconds`).
- **Память**: модель выгружается через `keep_alive: 15m` простоя — это нарочно, чтобы в играх была память.
- **Silero не грузится** (torch.hub без сети / ошибка): Колсон автоматически перейдёт на русский голос macOS.
  Посоветуй пользователю скачать «Юрий (улучшенный)» в Настройки → Универсальный доступ → Устный контент → Системный голос → Управление голосами.
- **Окно**: если `transparent`/`focus=False` в pywebview ведут себя странно на Tahoe — поправь `coulson/ui/window.py`.
  Режим без окна: `ui.enabled: false` в `config.local.yaml`.
- **Qwen3-TTS (британский тембр по-русски)**: `COULSON_QWEN3TTS=1 ./scripts/setup.sh`, затем
  `./scripts/make_voice_ref.sh` и `tts.engine: qwen3`. API mlx-audio меняется — сверь сигнатуры
  `load_model(...).generate(...)` в установленной версии и поправь `Speaker._synth_qwen`. Если медленно
  (> 1 с на фразу) — вернуть `silero`.

## Правила для правок
- Настройки пользователя — только в `config.local.yaml` (не в `config.yaml`).
- Новый инструмент: функция с декоратором `@registry.add(...)` в `coulson/tools/`, для опасных — `risk=`.
- Тесты: `uv run --group dev pytest -q`.
- VPN пользователь настроит позже: секция `vpn` (`scutil` — имя подключения из Настроек, `shortcut` — команды
  «<name> On/Off», `app` — имя приложения).
