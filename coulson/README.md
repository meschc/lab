# Колсон

Локальный голосовой ассистент для Мака в духе Джарвиса. Всегда слушает, откликается на «Колсон»,
управляет компьютером, видит экран и камеру, ищет в интернете, помнит тебя. Модели работают на твоём Маке,
в интернет он выходит только когда ищет информацию.

## Установка
Проще всего поручить её Claude Code на Маке:

```bash
git clone https://github.com/meschc/lab.git ~/lab
cd ~/lab && git checkout claude/coulson-voice-assistant
cd coulson && claude
```

и сказать ему: **«Установи и настрой Колсона по CLAUDE.md»**.

Вручную: `./scripts/setup.sh`, потом `open ~/Applications/Coulson.app`.

## Как говорить
| Скажи | Что будет |
|---|---|
| «Колсон, открой Стим» / «запусти Киберпанк» | запуск любого приложения или игры |
| «Колсон» … (сигнал) … «включи музыку» | сначала имя, потом команда |
| «Колсон, найди на Ютубе обзор M4» | откроет поиск в Яндекс Браузере |
| «Колсон, что нового по GTA 6?» | поищет в интернете и перескажет |
| «Колсон, что у меня на экране?» / «посмотри на меня» | зрение: экран или камера |
| «Колсон, громкость 30», «следующий трек» | звук и медиа |
| «Колсон, напомни через 20 минут выключить духовку» | таймер голосом |
| «Колсон, запомни: моя основная игра — Dota 2» | долговременная память (факты о тебе) |
| «Колсон, запиши идею: бот для заметок» / «добавь задачу купить подарок» | своя база заметок и задач |
| «Колсон, что у меня по задачам?» / «отметь подарок выполненным» | список, поиск, выполнение |
| «Колсон, что я думал про отпуск?» | поиск по смыслу в заметках, фактах и всех разговорах |
| «Колсон, подготовь всё к вечеру: открой Стим, Дискорд и сделай громче» | сам разобьёт на шаги и выполнит по плану |
| «Колсон, сделай таблицу, чем занят мой диск, с диаграммой» | посчитает папки и создаст Excel-таблицу с диаграммой |
| «Колсон, напиши HTML-страницу с моим портфолио» | создаст страницу и откроет её в браузере |
| «Колсон, что в файле отчёт.docx?» / «что в загрузках?» | прочитает файл, покажет папку |
| «Колсон, новая вкладка» / «нажми пробел» | горячие клавиши в любом приложении |
| «Колсон, нажми кнопку Войти» / «кликни по полю поиска» | найдёт элемент на экране и кликнет мышью |
| «Колсон, прокрути вниз» | прокрутка, перетаскивание |
| «Колсон, выключись» | завершить работу (или кнопка × в окне) |
| «Колсон, игровой режим» | выгрузить модель и отдать память игре |
| «Колсон, сделай скриншот и отправь в Максе Любимой» | найдёт в памяти, как записана Любимая, откроет Макс, проверит, что открыт нужный чат, спросит «отправить?» |
| «Колсон, подключи Яндекс Музыку» | вход по коду, как на телевизоре: вводишь код на странице Яндекса (один раз) |
| «Колсон, включи песню Кино — Группа крови» / «включи Кино» | включит именно эту песню (или лучшие треки исполнителя) из твоего аккаунта |
| «Колсон, включи мою волну» / «любимые» / «лайк» / «что играет» | «Моя волна», «Мне нравится», лайки — прямо в аккаунте |
| «Колсон, зайди на hh.ru и найди вакансии Python-разработчика в Москве» | сделает это сам во встроенном браузере |
| «Колсон, включи впн» / «проверь впн» | включит VPN и проверит, что выход не через Россию |
| «Колсон, попроси Клода сделать скрипт для…» | передаст задачу Claude Code (в фоне), озвучит итог, сохранит в заметки |
| «Колсон, открой Клод код» | откроет Claude Code в Терминале (VPN — автоматически) |
| «Колсон, разбери свои ошибки» / «почини себя» | самоанализ; самопочинка кода через Claude — с тестами и откатом |
| «Колсон, стоп» | перебить ответ |
| «Колсон, не слушай» / «Колсон, проснись» | режим сна |

Простые команды (громкость, пауза, следующий трек, «открой …», таймер, время, блокировка) выполняются
мгновенно, без нейросети, и работают даже в игровом режиме.
После ответа 8 секунд можно продолжать без имени («а теперь громче»), но не больше двух реплик подряд.
Опасные действия (удаление, sudo, выключение, отправка сообщений, перезапись существующих файлов)
он выполняет только после твоего «да».

## Из чего сделан
- **Слух**: Silero VAD + NVIDIA Parakeet v3 (MLX): русский и английский, десятки миллисекунд на фразу, почти не грузит Мак в фоне.
- **Мозг и зрение**: Ollama + Qwen3-VL 8B (картинки + инструменты), около 7 ГБ. Постоянная часть промпта кэшируется,
  поэтому ответ начинается примерно через секунду. При запуске игры модель выгружается и отдаёт память.
- **Голос**: Silero v5 (русский), британский Daniel (английский). Экспериментально — Qwen3-TTS с британским тембром по-русски.
- **Окно**: маленькая плашка справа сверху с голубым переливающимся шаром. Если что-то пошло не так
  или новость плохая, шар краснеет: при предупреждении наполовину, при ошибке целиком. Потом он снова голубой.
  Двойной клик по шару включает и выключает микрофон.
- **Скорость** на своём Маке проверяется командой `uv run python -m coulson --bench`.
- **Файлы** по умолчанию сохраняются в `~/Documents/Колсон`. Можно сказать «на рабочий стол».
- **Второй мозг**: факты, заметки, задачи и журнал всех разговоров хранятся локально в
  `~/Library/Application Support/Coulson/memory.db`. Поиск по смыслу работает на модели qwen3-embedding (0.6 ГБ).
  К каждой команде Колсон сам подмешивает пару самых похожих воспоминаний.
- **Планирование**: сложную просьбу Колсон разбивает на шаги и идёт по ним. В окне видно «шаг 2 из 5».
- **Связка с Claude**: сложные задачи (код, анализ, длинные тексты, исследования) Колсон отдаёт Claude Code,
  предварительно включив VPN и проверив, что страна выхода не Россия. Результат озвучивает и кладёт в заметки.
- **Эмодзи** в речи Колсон пропускает, а в сообщения может их вставлять.
- **Яндекс Музыка напрямую**: через API твоего аккаунта, без браузера и кликов. Играет фоновый плеер mpv,
  пауза и «следующий» работают голосом и медиаклавишами. Токен лежит в Связке ключей macOS, пароль Колсон не видит.
  Нужна подписка Плюс, иначе будут 30-секундные отрывки. API неофициальное и может сломаться после изменений у Яндекса.
  Этим же умеет пользоваться и Claude Code: MCP-сервер `yandex-music` регистрируется при установке.
- **Свой браузер**: у Колсона есть встроенный Chromium, отдельный от твоего. В нём он сам открывает сайты,
  жмёт кнопки, заполняет поля и включает музыку. Входы на сайты сохраняются. Показать тебе страницу он может
  в твоём Яндекс Браузере. Один раз войди в Яндекс Музыку в его браузере: «Колсон, открой яндекс музыку у себя».
- **Журнал ошибок** Колсон ведёт сам в `~/Documents/Колсон/Журнал ошибок Колсона.md`, его можно открыть и почитать.
- **Самоанализ**: ошибки инструментов, сбои и твои поправки («не то», «ты ошибся») пишутся в журнал.
  В простое Колсон разбирает его и выводит себе правила. Баги в своём коде по команде чинит через
  Claude Code: тесты должны пройти, иначе правки откатываются. Без твоего «да» свой код не меняет.

Настройки лежат в `config.yaml`. Свои изменения клади в `config.local.yaml`.
Обновление до свежей версии: `./scripts/update.sh`.
Если Колсон плохо узнаёт своё имя: `uv run python -m coulson --calibrate` (8 раз сказать «Колсон»).
