# Колсон

Локальный голосовой ассистент для Мака в духе Джарвиса. Всегда слушает, откликается на «Колсон»,
управляет компьютером, видит экран и камеру, ищет в интернете, помнит тебя. Модели работают на твоём Маке,
в интернет он выходит только когда ищет информацию.

## Установка
Проще всего поручить её Claude Code на Маке:

```bash
git clone https://github.com/meschc/lab.git ~/lab
cd ~/lab && git checkout claude/coulson-voice-assistant
cd coulson && claude
```

и сказать ему: **«Установи и настрой Колсона по CLAUDE.md»**.

Вручную: `./scripts/setup.sh`, потом `open ~/Applications/Coulson.app`.

## Как говорить
| Скажи | Что будет |
|---|---|
| «Колсон, открой Стим» / «запусти Киберпанк» | запуск любого приложения или игры |
| «Колсон» … (сигнал) … «включи музыку» | сначала имя, потом команда |
| «Колсон, найди на Ютубе обзор M4» | откроет поиск в Яндекс Браузере |
| «Колсон, что нового по GTA 6?» | поищет в интернете и перескажет |
| «Колсон, что у меня на экране?» / «посмотри на меня» | зрение: экран или камера |
| «Колсон, громкость 30», «следующий трек» | звук и медиа |
| «Колсон, напомни через 20 минут выключить духовку» | таймер голосом |
| «Колсон, запомни: моя основная игра — Dota 2» | долговременная память |
| «Колсон, сделай таблицу, чем занят мой диск, с диаграммой» | посчитает папки и создаст Excel-таблицу с диаграммой |
| «Колсон, напиши HTML-страницу с моим портфолио» | создаст страницу и откроет её в браузере |
| «Колсон, что в файле отчёт.docx?» / «что в загрузках?» | прочитает файл, покажет папку |
| «Колсон, новая вкладка» / «нажми пробел» | горячие клавиши в любом приложении |
| «Колсон, нажми кнопку Войти» / «кликни по полю поиска» | найдёт элемент на экране и кликнет мышью |
| «Колсон, прокрути вниз» | прокрутка, перетаскивание |
| «Колсон, выключись» | завершить работу (или кнопка × в окне) |
| «Колсон, игровой режим» | выгрузить модель и отдать память игре |
| «Колсон, стоп» | перебить ответ |
| «Колсон, не слушай» / «Колсон, проснись» | режим сна |

После ответа 8 секунд можно продолжать без имени («а теперь громче»).
Опасные действия (удаление, sudo, выключение, отправка сообщений, перезапись существующих файлов)
он выполняет только после твоего «да».

## Из чего сделан
- **Слух**: Silero VAD + NVIDIA Parakeet v3 (MLX): русский и английский, десятки миллисекунд на фразу, почти не грузит Мак в фоне.
- **Мозг и зрение**: Ollama + Qwen3-VL 8B (картинки + инструменты), около 7 ГБ. Постоянная часть промпта кэшируется,
  поэтому ответ начинается примерно через секунду. При запуске игры модель выгружается и отдаёт память.
- **Голос**: Silero v5 (русский), британский Daniel (английский). Экспериментально — Qwen3-TTS с британским тембром по-русски.
- **Окно**: маленькая плашка справа сверху с голубым переливающимся шаром. Если что-то пошло не так
  или новость плохая, шар краснеет: при предупреждении наполовину, при ошибке целиком. Потом он снова голубой.
  Двойной клик по шару включает и выключает микрофон.
- **Скорость** на своём Маке проверяется командой `uv run python -m coulson --bench`.
- **Файлы** по умолчанию сохраняются в `~/Documents/Колсон`. Можно сказать «на рабочий стол».

Настройки лежат в `config.yaml`. Свои изменения клади в `config.local.yaml`.
Обновление до свежей версии: `./scripts/update.sh`.
