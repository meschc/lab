# Колсон

Локальный голосовой ассистент для Мака в духе Джарвиса. Всегда слушает, откликается на «Колсон»,
управляет компьютером, видит экран и камеру, ищет в интернете, помнит тебя. Модели работают на твоём Маке,
в интернет он выходит только когда ищет информацию.

## Установка
Проще всего поручить её Claude Code на Маке:

```bash
git clone https://github.com/meschc/lab.git ~/lab
cd ~/lab && git checkout claude/coulson-voice-assistant
cd coulson && claude
```

и сказать ему: **«Установи и настрой Колсона по CLAUDE.md»**.

Вручную: `./scripts/setup.sh`, потом `open ~/Applications/Coulson.app`.

## Как говорить
| Скажи | Что будет |
|---|---|
| «Колсон, открой Стим» / «запусти Киберпанк» | запуск любого приложения или игры |
| «Колсон» … (сигнал) … «включи музыку» | сначала имя, потом команда |
| «Колсон, найди на Ютубе обзор M4» | откроет поиск в Яндекс Браузере |
| «Колсон, что нового по GTA 6?» | поищет в интернете и перескажет |
| «Колсон, что у меня на экране?» / «посмотри на меня» | зрение: экран или камера |
| «Колсон, громкость 30», «следующий трек» | звук и медиа |
| «Колсон, напомни через 20 минут выключить духовку» | таймер голосом |
| «Колсон, запомни: моя основная игра — Dota 2» | долговременная память |
| «Колсон, стоп» | перебить ответ |
| «Колсон, не слушай» / «Колсон, проснись» | режим сна |

После ответа 8 секунд можно продолжать без имени («а теперь громче»).
Опасные действия (удаление, sudo, выключение, отправка сообщений) он выполняет только после твоего «да».

## Из чего сделан
- **Слух**: Silero VAD + Whisper large-v3-turbo (MLX).
- **Мозг и зрение**: Ollama + Qwen3.5 9B (картинки + инструменты), около 7 ГБ, выгружается после 15 минут простоя.
- **Голос**: Silero v5 (русский), британский Daniel (английский). Экспериментально — Qwen3-TTS с британским тембром по-русски.
- **Окно**: маленькая плашка в стиле Siri справа сверху. Двойной клик по шару включает и выключает микрофон.

Настройки лежат в `config.yaml`. Свои изменения клади в `config.local.yaml`.
